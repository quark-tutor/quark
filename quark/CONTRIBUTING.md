# Contributing

Thanks for helping. This project is at the idea stage, so the most valuable contributions right now are thinking, writing and sketching, not code.

## Ways to contribute

- **Discuss.** Use GitHub Discussions for ideas, questions and "would this work in my house?"
- **Suggest a resource.** Open an issue with the "Resource suggestion" template.
- **Improve the docs.** Edit any page in `docs/` and open a pull request. On GitHub you can do this in the browser with the pencil icon.
- **Write a sample week.** One theme across all touch points, for one or two ages.
- **Sketch.** Mockups of the Wonder Wall or the parent digest. Attach images to an issue.

## Guidelines

- Keep kids' safety and privacy first. See [Safety and privacy](docs/07-safety-and-privacy.md).
- Favor free, high-quality, existing material over creating new content.
- Don't share personal details about your own children in public issues.
- Be kind. See the [Code of Conduct](CODE_OF_CONDUCT.md).
